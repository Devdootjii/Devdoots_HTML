Q1. What is Hashing? Explain division method to compute the hash function and also explain the collision resolution strategies used in hashing. [7 Marks · 2026]

Ans. Hashing is a technique of mapping a key k to a position (index) of a table, called the hash table, by using a function called the hash function h(k). It gives searching in O(1) average time because no comparison is required — the position is computed directly.

(a) Division Method

The hash function is defined as:

h(k) = k mod m    (where m = size of the hash table)

Example: Let m = 10 and key k = 45.
h(45) = 45 mod 10 = 5 → key 45 will be stored at index 5.

Note: m should be a prime number to reduce collisions.

(b) Collision

A collision occurs when two different keys map to the same index, e.g. h(23) = 3 and h(33) = 3 for m = 10. Collision cannot be avoided, so it is resolved by the following techniques.

(c) Collision Resolution Strategies

1. Chaining (Open Hashing): Each slot of the table stores a linked list. All keys mapping to the same slot are inserted in that list.

[2]12→NULL
[3]23→33→NULL
Fig. 1 — Chaining (keys 12, 23, 33 with m = 10)

2. Open Addressing: All keys are stored inside the table itself; another empty slot is searched.

  • Linear Probing: hi(k) = (h(k) + i) mod m,  i = 0, 1, 2, …
  • Quadratic Probing: hi(k) = (h(k) + i²) mod m,  i = 0, 1, 2, …
  • Double Hashing: hi(k) = (h(k) + i · h₂(k)) mod m

Load factor: α = n/m, where n = number of keys stored. Its ideal value is 0.5 to 0.75.

Complexity: Average case = O(1); Worst case = O(n) (when all keys map to one slot).

Q2. Explain linear probing and quadratic probing in hashing with examples. [7 Marks · 2026]

Ans. Both are open addressing techniques. When the home position h(k) is already occupied, the next positions are searched by a fixed rule.

(a) Linear Probing

In linear probing the next slot is checked one by one in a circular manner:

hi(k) = (h(k) + i) mod m,   i = 0, 1, 2, 3 …

Example: m = 10, keys = 23, 12, 45, 33, 9.

(b) Quadratic Probing

Here the gap increases as 1, 4, 9, 16 … (i²):

hi(k) = (h(k) + i²) mod m

Example: m = 10, insert 33 → h(33) = 3.

If slot 3 is full → (3 + 1²) = 4; if 4 is also full → (3 + 2²) = 7; if 7 is full → (3 + 3²) = 12 mod 10 = 2.

Q3. What are the disadvantages of linear probing in hashing? Discuss how quadratic probing can be used to solve some of these problems. [7 Marks · 2024]

Ans. Disadvantages of Linear Probing:

  • Primary clustering: continuous occupied slots form a block. Any new key whose home slot falls in this block is pushed further, so the block grows and search time increases.
  • More probes: as the table becomes full, the number of comparisons per search increases rapidly.
  • Deletion problem: an element cannot be deleted simply by making the slot empty, because the probe chain of other keys will break. A special marker called tombstone is required.
  • Poor performance at high load factor: when α → 1, search becomes almost O(n).

How Quadratic Probing helps: in quadratic probing the step size is i², i.e. 1, 4, 9, 16 … instead of 1, 2, 3. Therefore two keys having nearby home positions do not occupy consecutive slots; the occupied slots are spread out. This breaks the long blocks, so primary clustering is removed and the average number of probes decreases.

Limitation: quadratic probing still causes secondary clustering — two keys with the same home position follow the same probe sequence. Double hashing removes this problem.

Q4. What are the 2 different forms of hashing? [2 Marks · 2024]

Ans. (i) Open Hashing (Chaining) — the collision keys are stored in a linked list outside the table; the table never becomes full.
(ii) Closed Hashing (Open Addressing) — all keys are stored inside the table itself and an empty slot is found by probing.

Q5. Explain any three commonly used hash functions with suitable examples. [10 Marks · 2020-21]

Ans. A hash function converts a key into a valid table index. Three commonly used hash functions are:

1. Division Method

h(k) = k mod m, where m is the table size (preferably prime).

Example: m = 10, k = 45 → h(45) = 45 mod 10 = 5.
k = 23 → 23 mod 10 = 3.

Advantage: very simple and fast; Disadvantage: if m has many factors, collisions increase — hence m is chosen prime.

2. Mid-Square Method

The key is squared and the middle digits of the result are taken as the index.

Example: k = 23 → k² = 529. The middle digit is 2, so h(23) = 2.
k = 45 → 45² = 2025 → middle digit 0 → h(45) = 0.

Advantage: the middle digits depend on all the digits of the key, so the distribution is good.

3. Folding Method

The key is divided into parts of equal size and all parts are added; the sum (mod m) is the index.

Example: k = 123456 → parts 12, 34, 56 → sum = 102 → h(k) = 102 mod 10 = 2.

4. Multiplication Method (for reference)

h(k) = ⌊ m × (k·A mod 1) ⌋, where A ≈ 0.618 (golden ratio).
Example: m = 10, k = 45 → 45 × 0.618 = 27.81 → fraction 0.81 → 10 × 0.81 = 8.

Conclusion

A good hash function should be easy to compute, should give uniform distribution of keys, and should minimise collisions. The division method is used most in practice.

Ans. Insertion sort works like arranging playing cards in hand: each element is picked and inserted at its correct position among the already sorted elements, shifting the bigger elements to the right.

Algorithm
1. for i = 1 to n−1
2.    key = a[i]
3.    j = i − 1
4.    while (j ≥ 0 and a[j] > key)
5.       a[j+1] = a[j]   (shift right)
6.       j = j − 1
7.    a[j+1] = key   (insert)
8. end for

Q11. Write an algorithm for Heap Sort. Use Heap sort algorithm to sort the following sequence: 18, 25, 45, 34, 36, 51, 43, 24. [10 Marks · 2026 / 2022-23]

Ans. Heap sort builds a max-heap (parent ≥ children) in the array, then repeatedly moves the largest element (root) to the end and heapifies the remaining part.

For a node at index i: left child = 2i+1, right child = 2i+2.

Algorithm
heapify(a, n, i):
  largest = i; l = 2i+1; r = 2i+2
  if (l < n and a[l] > a[largest]) largest = l
  if (r < n and a[r] > a[largest]) largest = r
  if (largest ≠ i) { swap(a[i], a[largest]); heapify(a, n, largest) }

heapSort(a, n):
  for i = n/2−1 down to 0 : heapify(a, n, i)   // build max-heap
  for i = n−1 down to 1 : swap(a[0], a[i]); heapify(a, i, 0)

Q12. Write an algorithm for Quick sort. Use Quick sort to sort the following elements: 2, 8, 7, 1, 3, 5, 6, 4. Is it a stable sorting algorithm? Justify. [10 Marks · 2022-23]

Ans. Quick sort selects a pivot and partitions the array so that all smaller elements come to its left and larger to its right. The pivot then reaches its final position, and the same process is repeated on the left and right parts.

Algorithm
quickSort(a, low, high):
  if (low < high) {
    pi = partition(a, low, high)
    quickSort(a, low, pi−1)
    quickSort(a, pi+1, high) }

partition(a, low, high):
  pivot = a[high]; i = low − 1
  for j = low to high−1:
    if (a[j] ≤ pivot) { i++; swap(a[i], a[j]) }
  swap(a[i+1], a[high]); return i+1

Step 3 — Stability

Quick sort is NOT stable. During partitioning, elements are swapped over long distances. If two elements have equal keys, their relative order may change. Hence quick sort is unstable. (Example: in the partition step 8 was swapped with 1, jumping over several elements.)

Complexity: Best/Average = O(n log n) · Worst = O(n²) (when the array is already sorted and the last element is taken as pivot) · Space = O(log n) · In-place.

Q13. Write a C program for sorting 100 integer numbers using selection sort procedure. Discuss the worst-case time complexity of the algorithm. [7 Marks · 2024]

Ans. Selection sort finds the smallest element from the unsorted part in every pass and swaps it with the first element of that part.

C Program
#include <stdio.h>
int main() {
  int a[100], n, i, j, min, temp;
  printf("Enter number of elements: ");
  scanf("%d", &n);
  for (i = 0; i < n; i++)
    scanf("%d", &a[i]);

  for (i = 0; i < n - 1; i++) {   // n−1 passes
    min = i;
    for (j = i + 1; j < n; j++)
      if (a[j] < a[min]) min = j;
    if (min != i) {
      temp = a[i]; a[i] = a[min]; a[min] = temp;
    }
  }

  printf("Sorted array: ");
  for (i = 0; i < n; i++) printf("%d ", a[i]);
  return 0;
}
Working (example)

Array: 64, 25, 12, 22, 11

212 (index 2)25 ↔ 1211, 12, 25, 22, 64

Worst-case time complexity

In every pass the inner loop scans the complete unsorted part to find the minimum. The number of comparisons is:

(n−1) + (n−2) + … + 1 = n(n−1)/2

Hence the time complexity is O(n²) in the worst case, average case and even the best case (because the full scan is always required).

Space: O(1) · Swaps: only (n−1) — minimum among all sorting algorithms · Unstable.

Q14. Illustrate the concept of Indexed Sequential search. [2 Marks · 2025]

Ans. In indexed sequential search the sorted file is divided into blocks and an index table is created which stores the starting key and address of each block. First the index table is searched to locate the block, then a linear search is performed only inside that block. It reduces the search time to approximately O(√n) and is useful for large files stored on disk.

Q15. Differentiate between linear and binary search algorithm. Write a recursive function to implement binary search. [10 Marks · 2021-22]

Ans. Linear search compares the key with every element one by one from the beginning. Binary search compares the key with the middle element and discards half of the array in each step.

Recursive binary search function
int binarySearch(int a[], int low, int high, int key) {
  if (low > high) return -1;   // base case: not found
  int mid = (low + high) / 2;
  if (a[mid] == key) return mid;   // found
  if (a[mid] > key)   // key is smaller
    return binarySearch(a, low, mid - 1, key);
  return binarySearch(a, mid + 1, high, key);
}

Complexity of recursive binary search: the array size becomes half at every call, so there are log₂n calls. Hence O(log n) time and O(log n) recursion stack space.

Q16. How does the choice of pivot element affect the running time of quick sort algorithm? [2 Marks · 2024]

Ans. The pivot decides how the array is partitioned. If the pivot divides the array into two nearly equal halves, the recursion depth is log₂n and the time is O(n log n). But if the pivot is always the smallest or largest element (e.g. the last element of an already sorted array), the partition splits into 0 and n−1 elements, the recursion becomes n, n−1, n−2 … and the time becomes O(n²). Therefore a random pivot or median-of-three is used.
