PYQ — Theory (model answers ke saath)

Har question ke saath: marks, saal, aur exam-ready answer

7 marks · 2026 What is Hashing? Explain division method to compute the hash function and also explain the collision resolution strategies used in hashing.

Hashing: Mapping keys to positions of a hash table using a hash function h(k), giving near-constant-time search. Average O(1), worst O(n).

Division method: h(k) = k mod m — remainder is the index. Example: m = 10, k = 45 → 45 mod 10 = 5. m should be prime.

Collision: two keys mapping to the same index (h(23) = h(33) = 3). Resolution:

1. Chaining — every slot holds a linked list of keys.
2. Open addressing — Linear probing: hi(k) = (h(k) + i) mod m · Quadratic: hi(k) = (h(k) + i²) mod m · Double hashing: hi(k) = (h(k) + i·h2(k)) mod m.

Load factor: α = n/m, ideal 0.5–0.75.

7 marks · 2026 Explain linear probing and quadratic probing in hashing with examples.

Linear probing: if the slot is occupied, check the next slot, then next… (circularly). Formula: hi(k) = (h(k) + i) mod m, i = 0,1,2…

Example (m = 10): insert 23 → 3 · 12 → 2 · 45 → 5 · 33 → 3 (bhara) → 4 · 9 → 9.

Quadratic probing: gaps of i² (1, 4, 9, 16…). Formula: hi(k) = (h(k) + i²) mod m.

Example: 33 → 3 bhara → (3+1) = 4 · agar 4 bhi bhara → (3+4) = 7 · phir (3+9) = 12 mod 10 = 2.

Fark: linear me primary clustering hoti hai (ek block ban jata hai); quadratic me clustering kam hoti hai.

7 marks · 2024 What are the disadvantages of linear probing in hashing? Discuss how quadratic probing can be used to solve some of these problems.

Disadvantages: (1) Primary clustering — continuous bhare slots ka block ban jata hai, jisse aage ki keys bhi usi block me girti hain (2) search ke probes badh jate hain (3) deletion ke liye tombstone chahiye (4) table bharne pe performance O(n) tak gir jati hai.

Quadratic ka fix: step i² hota hai (1, 4, 9…) — isliye keys ek hi block me nahi girte, clustering tootti hai aur average probes kam ho jate hain. (Par secondary clustering reh jati hai.)

2 marks · 2024 What are the 2 different forms of hashing?

1. Open hashing (chaining) — collision wali keys ek linked list me, table ke bahar.
2. Closed hashing (open addressing) — sab keys table ke andar hi, probing se.

10 marks · 2020-21 Explain any three commonly used hash functions with suitable examples.

1. Division: h(k) = k mod m · k = 45, m = 10 → 5
2. Mid-square: k² karo, beech ke digits lo · k = 23 → 529 → beech ka digit 2
3. Folding: key ko tukdon me todo aur jodo · 123456 → 12+34+56 = 102 → mod 10 = 2
4. Multiplication: h(k) = ⌊m × (k·A mod 1)⌋, A ≈ 0.618 · k = 45, m = 10 → 0.81 × 10 = 8

(Teen likhne hain toh koi bhi teen — par Division + Mid-square + Folding safest hain.)

2 marks · 2025 Illustrate the concept of Indexed Sequential search.

Bade sorted file ko blocks me baanto aur har block ka ek index table banao (block ka starting key + address). Search me pehle index table se block decide karo, phir sirf usi block me linear search. Complexity ~√n — bade files ke liye useful.

10 marks · 2021-22 Differentiate between linear and binary search. Write a recursive function to implement binary search.

Difference: linear — sorted ki zaroorat nahi, O(n), har element check · binary — sorted compulsory, O(log n), beech se aadha kaatta hai.

Recursive binary search:

int binarySearch(int a[], int low, int high, int key) {
    if (low > high) return -1;              // base case: nahi mila
    int mid = (low + high) / 2;              // beech
    if (a[mid] == key) return mid;          // mil gaya
    if (a[mid] > key)                        // key chhoti hai
        return binarySearch(a, low, mid - 1, key);   // left half
    return binarySearch(a, mid + 1, high, key);      // right half
}
2 marks · 2024 How does the choice of pivot element affect the running time of quick sort?

Pivot agar har baar array ko aadha baante → O(n log n). Pivot hamesha sabse chhota/bada (jaise sorted array me last element) → partition 0 aur n−1 me bant jata hai → O(n²). Isliye random pivot ya median-of-three use karte hain.

2 marks · 2021-22 Give one example each of stable and unstable sorting techniques.

Stable: Merge sort (ya insertion/bubble/radix) — barabar keys ka order bacha rehta hai.
Unstable: Quick sort (ya selection/heap) — order badal sakta hai.

10 marks · 2022-23 Write an algorithm for Quick sort and sort 2, 8, 7, 1, 3, 5, 6, 4.

Partition 1 (pivot = 4, last element):

2 ≤ 4 → left me · 8 ✕ · 7 ✕ · 1 ≤ 4 → swap · 3 ≤ 4 → swap · 5 ✕ · 6 ✕ → 2, 1, 3, 8, 7, 5, 6, 4 pivot 4 ko i+1 (index 3) pe rakho → 2, 1, 3, 4, 7, 5, 6, 8 4 FINAL (index 3) ✔

Left [2,1,3] → pivot 3 → 2,1,3 → 3 final · [2,1] → pivot 1 → 1,2 · Right [7,5,6,8] → pivot 8 → 7,5,6,8 → 8 final · [7,5,6] → pivot 6 → 5,6,7 · [7] done.

Final: 1, 2, 3, 4, 5, 6, 7, 8 ✔

Stable? Nahi — partition me swap se barabar elements ka order badal sakta hai. Average O(n log n), worst O(n²).

7 marks · 2024 Write a C program to sort 100 integers using selection sort. Discuss its worst-case time complexity.
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {     // n-1 passes
        int min = i;                      // maan lo i hi minimum hai
        for (int j = i + 1; j < n; j++) // baaki me dhoondho
            if (a[j] < a[min]) min = j;    // chhota mila → yaad rakho
        if (min != i) {                   // swap
            int t = a[i]; a[i] = a[min]; a[min] = t;
        }
    }
}

Worst case: O(n²) — (n−1) + (n−2) + … + 1 = n(n−1)/2 comparisons. Best case bhi O(n²) (poora scan hamesha). Space O(1), unstable, swaps sirf n−1.

BINARY SEARCH — skeleton (likhne layak)

low = 0; high = n−1;
while (low <= high) {
  mid = (low + high) / 2;
  if (a[mid] == key) return mid;
  else if (a[mid] < key) low = mid + 1;
  else high = mid − 1;
}
return −1;

YAAD RAKHO

1000 elements me binary = ~10 steps · 10 lakh = ~20
Binary me low = mid + 1 (sirf mid nahi — warna infinite loop)
Linear me return −1 loop ke bahar

B. HASHING

4 HASH FUNCTIONS

1. Division: h(k) = k mod m
2. Mid-square: k² ka beech ka digit
3. Folding: key ke tukde jodo → mod m
4. Multiplication: h(k) = ⌊m × (k·A mod 1)⌋, A ≈ 0.618

4 COLLISION METHODS

1. Chaining: har seat pe linked list
2. Linear probing: hi = (h(k) + i) mod m
3. Quadratic: hi = (h(k) + i²) mod m
4. Double hashing: hi = (h(k) + i·h₂(k)) mod m

LOAD FACTOR

α = n/m · ideal 0.5–0.75 · α > 1 → rehashing
Average O(1) · worst O(n) (sab ek seat pe)

TRAPS

Deletion → tombstone (warna probe chain tootegi)
Probings circular hain (mod m — aakhir ke baad 0 pe wapas)
Linear probing ki problem = primary clustering

KAB KAUNSA

Chhota/nearly sorted → Insertion · Guarantee → Merge/Heap · Speed → Quick · Memory kam → Heap/Quick · Stable → Merge/Radix · Numbers → Radix · Search → Hashing

D. Code skeletons (exam me likhne layak)

BUBBLE

for i = 0 … n−2
  for j = 0 … n−2−i
    if (a[j] > a[j+1]) swap

SELECTION

for i = 0 … n−2
  min = i; for j = i+1 … n−1
    if (a[j] < a[min]) min = j
  if (min != i) swap(a[i], a[min])

INSERTION

for i = 1 … n−1
  key = a[i]; j = i−1
  while (j ≥ 0 && a[j] > key)
    a[j+1] = a[j]; j−−
  a[j+1] = key

MERGE

mergeSort(l, r): if (l >= r) return
  m = (l+r)/2; sort(l,m); sort(m+1,r); merge(l,m,r)
merge: do pointers, chhota pehle, bacha hua copy

QUICK

quickSort(low, high): if (low < high)
  pi = partition(low, high)
  sort(low, pi−1); sort(pi+1, high)
partition: pivot = a[high]; chhote left me

HEAP

build: for i = n/2−1 … 0 heapify(i)
sort: for i = n−1 … 1
  swap(a[0], a[i]); heapify(i, 0)
bachche: 2i+1, 2i+2
