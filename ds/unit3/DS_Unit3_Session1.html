01

Linear Search — ek-ek karke dekho

Sabse simple search · kisi bhi array pe chalta hai · O(n)

Linear search = pehle element se shuru karo, ek-ek karke key se compare karo, mil jaye toh index return karo, warna −1. Sabse bada faayda: array sorted hona zaroori nahi. Nuksaan: worst case me poore n comparisons — O(n).

DEFINITION — SCREEN PE LIKHO

Linear (Sequential) Search: A search that compares the key with each element one by one from the beginning until a match is found or the list ends. Works on unsorted data; worst case O(n).

Ab code — ek loop, ek if, milte hi return i (loop wahin ruk jata hai):

/* SEQUENTIAL (LINEAR) SEARCH — C program */
#include <stdio.h>

int linearSearch(int a[], int n, int key) {
    int i;
    for (i = 0; i < n; i++) {
        if (a[i] == key)              // mil gaya
            return i;                 // index return karo
    }
    return -1;                        // nahi mila
}

int main() {
    int a[100], n, i, key, pos;
    printf("Enter number of elements: ");
    scanf("%d", &n);
    printf("Enter %d elements: ", n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);

    printf("Enter key to search: ");
    scanf("%d", &key);

    pos = linearSearch(a, n, key);
    if (pos == -1) printf("Element not found\n");
    else           printf("Element found at index %d\n", pos);
    return 0;
}
DRY RUN — [10, 25, 30, 45, 60] · key = 45
i=0: 10 == 45 ? nahi i=1: 25 == 45 ? nahi i=2: 30 == 45 ? nahi i=3: 45 == 45 ? HAAN → return 3 ✔ 4 comparisons lage

Poochho: "agar key 60 hoti toh kitne comparisons?" (5) · "aur agar key array me hi na ho?" (5 — poora scan, phir −1)

🧠 Yaad rakhne ka tareeka
  • Linear = almari ke ek-ek dabbe kholo
  • Best O(1) (pehla element hi mil gaya) · Worst O(n) (last ya nahi mila) · Average O(n)
  • Sorted ki zaroorat nahi — yahi iska plus point hai
Exam pointer (2 marks): "Linear search kya hai? Complexity?" → definition + O(n) + "unsorted data pe chalta hai" — teen line me full answer.
02

Binary Search — aadha kaato

Sorted array hi chalega · O(log n) · 1000 me sirf ~10 steps

Dictionary me shabd dhoondhne jaisa: beech dekho → barabar? mila. Chhoti hai? left half. Badi hai? right half. Har step me aadha hamesha ke liye hat jata hai — isliye O(log n). Shart: array sorted ho.

DEFINITION — SCREEN PE LIKHO

Binary Search: A search on a sorted array that compares the key with the middle element and discards half of the remaining elements each step. Requires sorted data; O(log n) — 1000 elements me ~10 comparisons.

⚡ SEARCH BEAM— linear aur binary saath chalao, comparisons gino
LINEAR: 0 comparisons BINARY: 0 comparisons Target daalo aur START dabao.
Array: [3, 9, 12, 18, 23, 31, 40, 47, 56, 60] — sorted hai, isliye dono chal sakte hain.

Ab code — teen variable: low, mid, high. Loop tab tak jab tak low <= high:

/* BINARY SEARCH (iterative) — C program. Array SORTED hona chahiye! */
#include <stdio.h>

int binarySearch(int a[], int n, int key) {
    int low = 0, high = n - 1, mid;

    while (low <= high) {
        mid = (low + high) / 2;        // beech ka index

        if (a[mid] == key)
            return mid;                // mil gaya
        else if (a[mid] < key)
            low = mid + 1;             // right half me dhoondo
        else
            high = mid - 1;            // left half me dhoondo
    }
    return -1;                        // nahi mila
}

int main() {
    int a[100], n, i, key, pos;
    printf("Enter number of elements: ");
    scanf("%d", &n);
    printf("Enter %d elements in SORTED order: ", n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);

    printf("Enter key to search: ");
    scanf("%d", &key);

    pos = binarySearch(a, n, key);
    if (pos == -1) printf("Element not found\n");
    else           printf("Element found at index %d\n", pos);
    return 0;
}

03

Bubble Sort — sabse aasaan sorting

Adjacent swap · har pass me ek bada element settle · O(n²)

Bubble sort = paas-paas wale do elements compare karo, pehla bada ho toh swap. Ek poora pass chalne pe sabse bada element end me pahunch jata hai (bubble ki tarah upar aata hai). Agla pass, phir agla…

DEFINITION — SCREEN PE LIKHO

Bubble Sort: A sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order; after each pass the largest remaining element settles at its final position. O(n²) average/worst, O(n) best (already sorted), in-place, stable.

/* BUBBLE SORT — C program */
#include <stdio.h>
int main() {
    int a[100], n, i, j, temp;
    printf("Enter number of elements: ");
    scanf("%d", &n);
    printf("Enter %d elements: ", n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);

    for (i = 0; i < n - 1; i++) {          // n-1 passes
        for (j = 0; j < n - 1 - i; j++) {  // last i elements sorted hain
            if (a[j] > a[j + 1]) {          // galat order
                temp = a[j];                // swap
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
    printf("Sorted array: ");
    for (i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}

PLAY dabao — har swap pe bars badalte dikhenge.
DRY RUN — [5, 1, 4, 2, 8] · har pass ke baad
pass 1: 1 4 2 5 8 ← 8 apni jagah pe pass 2: 1 2 4 5 8 pass 3: 1 2 4 5 8 pass 4: 1 2 4 5 8 ✔ sorted

Poochho: "pass 1 me kitne swaps hue?" (3) · "4 passes kyun, 5 nahi?" (n−1 passes kaafi hote hain)

🧠 Yaad rakhne ka tareeka
  • Bubble = paani ke bulbule — bada element upar (end) chala jata hai
  • Har pass ke baad ek element final ho jata hai → isliye inner loop n-1-i tak
  • Best case O(n) (already sorted, koi swap nahi) · worst O(n²) · space O(1) · stable
Exam pointer (5 marks): "Sort 5, 1, 4, 2, 8 using bubble sort — show each pass" + program. Pass-by-pass table banana mat bhoolna.
