Hashing — formula se seat

h(k) = k mod m · collision · chaining · probing · load factor

Analogy — class ki tay seat. Har student ki seat pehle se fix hai. Roll 23 aaya? Formula lagao → seat number → seedha wahan jao. Ek bhi naam check nahi karna. Yahi hashing hai.

DEFINITION — SCREEN PE LIKHO

Hashing: Mapping keys to positions of a hash table using a hash function h(k), giving near-constant-time search. Collision = two keys mapping to the same index. Load factor α = n/m (ideal 0.5–0.75).

h(k) = k mod m k = key · m = table size · mod = remainder — remainder hi seat number hai. m = 10 → seats 0 se 9.
⚡ KEY → SEAT ANIMATION— har key apni seat tak chalti hui, collision pe flash
STEP dabao — pehli key se shuru karein.
LOAD FACTOR α = 0.00
Keys queue me hain — STEP se ek-ek insert hoga.

Code — har line ka matlab (insert with linear probing)

/* ============ HASH TABLE: insert with LINEAR PROBING ============ */
#define M 10                            // table ka size — 10 slots (0 se 9)
int table[M];                            // hash table — yahan keys rahengi
int used[M];                             // har slot bhara hai (1) ya khaali (0)

void init() {                           // program shuru hote hi
    for (int i = 0; i < M; i++)          // har slot ke liye
        used[i] = 0;                     // 0 = khaali mark karo
}

int hash(int key) {                     // hash function
    return key % M;                      // remainder = seat number (0..9)
}

int insert(int key) {                   // key daalo, index lautao (-1 = full)
    int h = hash(key);                   // pehle GHAR (home address) nikalo

    for (int i = 0; i < M; i++) {          // max M tries (warna infinite loop)
        int pos = (h + i) % M;           // i=0 → ghar, i=1 → ek aage, ... (circular)

        if (!used[pos]) {                // slot khaali mila?
            table[pos] = key;            // → key wahan rakho
            used[pos] = 1;               // → slot ko bhara mark karo
            return pos;                   // → index lautao
        }
        // warna slot bhara hai → loop ka agla i (probe)
    }
    return -1;                          // table FULL — insert nahi hua
}

02

Selection Sort — sabse chhota chuno

Minimum dhoondho, aage rakho · minimum swaps · har case O(n²)

Analogy — sabse chhota aage. Class me sabse chhote bachche ko pehli jagah khada karna hai. Poori line dekho → sabse chhota dhoondho → pehli jagah pe khada kar do. Phir baaki line me wahi karo.

DEFINITION — SCREEN PE LIKHO

Selection Sort: Repeatedly selects the smallest element from the unsorted part and swaps it with the first unsorted position. O(n²) in all cases, O(1) space, unstable, performs minimum swaps (n−1).

/* ============ SELECTION SORT ============ */
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {      // n-1 passes (aakhri element apne aap sahi)
        int min = i;                       // maan lo i hi sabse chhota hai

        for (int j = i + 1; j < n; j++) {  // baaki unsorted hissa dekho
            if (a[j] < a[min])             // isse bhi chhota mila?
                min = j;                   // → naya minimum yaad rakho
        }

        if (min != i) {                    // minimum aage hi hai? (faltu swap nahi)
            int t = a[i];                  // swap shuru — purani value bachao
            a[i] = a[min];                 // chhota element aage le aao
            a[min] = t;                    // purani value peeche
        }
    }
}

Poochho: "pass 1 me minimum kaise mila?" (poora unsorted hissa dekha) · "kitne swaps?" (3)

TRAP — BEST CASE BHI O(n²)

Array sorted ho tab bhi O(n²) — minimum dhoondhne ke liye poora scan hamesha karna padta hai.

UNSTABLE KYUN?

[3a, 3b, 1] → min = 1, swap 3a ↔ 1 → [1, 3b, 3a]. 3a aur 3b ka order badal gaya.

🧠 Yaad rakhne ka tareeka
  • Selection = "sabse chhota chuno, aage rakho"
  • Har case O(n²) · space O(1) · unstable · swaps sabse kam (n−1)
  • Common galti: min = 0 likhna (sahi: min = i)
03

Insertion Sort — taash ke patte

Card uthao, sahi jagah pe daalo · nearly-sorted pe O(n)

Analogy — taash ke patte. Ek-ek card uthao aur sorted hisse me sahi jagah pe daal do. Jagah banane ke liye bade cards ek-ek kadam shift hote hain (swap nahi).

DEFINITION — SCREEN PE LIKHO

Insertion Sort: Builds the sorted array one element at a time by inserting each element into its correct position among the already sorted elements, shifting larger elements right. Best O(n), average/worst O(n²), O(1) space, stable.

/* ============ INSERTION SORT ============ */
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {          // i=1 se (pehla element akela sorted hai)
        int key = a[i];                     // naya card uthaya
        int j = i - 1;                      // uske peeche wale se compare shuru

        while (j >= 0 && a[j] > key) {       // jab tak peeche wala bada hai (aur index valid)
            a[j + 1] = a[j];               // → usse ek kadam aage SHIFT karo (swap nahi)
            j--;                           // → aur peeche jao
        }

        a[j + 1] = key;                     // khaali jagah pe key daal do (INSERT)
    }
}
