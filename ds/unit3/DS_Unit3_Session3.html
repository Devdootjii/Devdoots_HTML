01

Merge Sort — todo, phir jodo

Divide & conquer · har case O(n log n) · stable · O(n) space

Analogy — do patton ke dher. Maan lo do dher hain, dono already sorted. Ek sorted dher banana hai: dono ke upar wale patte dekho, jo chhota hai wo pehle uthao. Bas yahi merge hai. Aur aise sorted dher banane ke liye pehle array ko aadha-aadha todte jao jab tak 1-1 element na bache (1 element toh hamesha sorted hota hai).

DEFINITION — SCREEN PE LIKHO

Merge Sort: A divide-and-conquer algorithm that splits the array into halves, recursively sorts each half, and merges the two sorted halves using two pointers. O(n log n) in all cases, O(n) extra space, stable.

STEP 1 — TODO (DIVIDE)

Array ko beech se do hisson me todo. Har hisse pe wahi kaam (recursion). Jab 1 element bacha → ruk jao (base case) — kyunki 1 element already sorted hai.

STEP 2 — JODO (MERGE)

Ab do sorted hisse aaye hain. Dono ke shuru me ek-ek pointer. Jo chhota hai wo output me, uska pointer aage. Ek hissa khatam → bacha hua poora copy.

/* ============ MERGE: do sorted halves ko jodo ============ */
void merge(int a[], int l, int m, int r) {   // l = left, m = beech, r = right
    int n1 = m - l + 1;                 // left half me kitne elements (l se m tak)
    int n2 = r - m;                     // right half me kitne elements (m+1 se r tak)
    int L[n1], R[n2];                   // dono halves ke liye temp arrays
    int i, j, k;                        // i = left pointer, j = right pointer, k = result pointer

    for (i = 0; i < n1; i++)            // left half ko copy karo
        L[i] = a[l + i];                // a[l]…a[m]  →  L[0]…L[n1-1]

    for (j = 0; j < n2; j++)            // right half ko copy karo
        R[j] = a[m + 1 + j];            // a[m+1]…a[r]  →  R[0]…R[n2-1]

    i = 0;                              // left pointer shuru se
    j = 0;                              // right pointer shuru se
    k = l;                              // result original array me index l se shuru

    while (i < n1 && j < n2) {           // jab tak DONO me kuch bacha hai
        if (L[i] <= R[j])               // left wala chhota (ya barabar) hai?
            a[k++] = L[i++];            // → left wala output me, i aage
        else                            // warna right wala chhota hai
            a[k++] = R[j++];            // → right wala output me, j aage
    }

    while (i < n1)                       // left me kuch bacha hai?
        a[k++] = L[i++];                // → baaki left copy kar do

    while (j < n2)                       // right me kuch bacha hai?
        a[k++] = R[j++];                // → baaki right copy kar do
}

/* ============ MERGE SORT: todo aur merge ============ */
void mergeSort(int a[], int l, int r) {
    if (l >= r)                         // BASE CASE: 0 ya 1 element bacha
        return;                         // → pehle se sorted hai, wapas jao

    int m = l + (r - l) / 2;            // beech ka index (l+r)/2 hi hai, par overflow-safe
    mergeSort(a, l, m);                 // LEFT half ko recursively sort karo
    mergeSort(a, m + 1, r);             // RIGHT half ko recursively sort karo
    merge(a, l, m, r);                  // dono sorted halves ko jodo
}
T(n) = 2·T(n/2) + O(n)  ⇒  O(n log n) 2·T(n/2) = do halves ki recursion · O(n) = merge ka kaam · levels = log₂n · har level pe n kaam. Best, average, worst — teeno same.
🧠 Yaad rakhne ka tareeka
  • Merge = todo, phir jodo. Sorting merge ke waqt hoti hai
  • Har case O(n log n) — koi surprise nahi · stable ✔ · space O(n)
  • Recursion samajhne ka rule: jaate waqt todo, aate waqt jodo (call stack LIFO)
  • Base case if (l >= r) return; — bhoolna = infinite recursion
Exam pointer (10 marks): tree diagram + merge() ka logic (do pointers) + T(n) = 2T(n/2) + O(n) + "stable, O(n) space". Yeh chaar cheezein likhne se full marks.
02

Quick Sort — pivot se baanto

Partition · pivot apni final jagah pe · average O(n log n), worst O(n²)

Analogy — line me khade bachche. Ek bachche ko pivot banao (jaise 5 feet wala). Bolo: "5 se chhote left me, 5 se lambe right me." Ek baar line baant gayi → pivot apni sahi jagah pe (uske left me sab chhote, right me sab lambe). Phir left group aur right group pe wahi kaam dohrao.

DEFINITION — SCREEN PE LIKHO

Quick Sort: A divide-and-conquer algorithm that picks a pivot, partitions the array so smaller elements lie left and larger right (pivot reaches its final position), then recursively sorts both parts. Average O(n log n), worst O(n²), O(log n) space, unstable.

Code — har line ka matlab

/* ============ PARTITION: pivot ko sahi jagah pe rakho ============ */
int partition(int a[], int low, int high) {
    int pivot = a[high];                // pivot = aakhri element
    int i = low - 1;                     // i = chhote hisse ka last index (abhi khaali)

    for (int j = low; j < high; j++) {   // har element dekho (pivot chhod ke)
        if (a[j] <= pivot) {             // pivot se chhota ya barabar?
            i++;                         // chhote hisse ki jagah ek badhao
            int t = a[i];                // swap shuru — purani value bachao
            a[i] = a[j];                 // chhota element left me le jao
            a[j] = t;                    // purani value uski jagah
        }
    }

    int t = a[i + 1];                   // pivot ko uski FINAL jagah pe le jao
    a[i + 1] = a[high];                  // jo wahan tha use pivot ki purani jagah
    a[high] = t;                         // pivot ab i+1 pe
    return i + 1;                        // pivot ka final index lautao
}

/* ============ QUICK SORT: pivot ke left/right pe recursion ============ */
void quickSort(int a[], int low, int high) {
    if (low < high) {                    // 2 ya zyada elements hain?
        int pi = partition(a, low, high); // pivot ko sahi jagah pe rakho
        quickSort(a, low, pi - 1);       // LEFT part sort karo (pivot se chhote)
        quickSort(a, pi + 1, high);      // RIGHT part sort karo (pivot se bade)
    }
}

Worst case kyun? Sorted array me aakhri element sabse bada hota hai → partition me left 0, right n−1. Aadha nahi hota, isliye recursion n, n−1, n−2… = O(n²). Fix: random pivot ya median-of-three.

MERGE KAB

Jab worst case ki guarantee chahiye (real-time systems), ya stability chahiye, ya data linked list me hai.

QUICK KAB

Jab speed chahiye aur memory kam hai (in-place), aur data random hai (worst case ka risk kam).

🧠 Ek line me

"Guarantee chahiye → Merge · Speed chahiye → Quick." Dono O(n log n) average dete hain, fark worst case aur memory ka hai.
