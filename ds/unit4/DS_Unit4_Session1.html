UNIT 4 · SESSION 1 TREES · BASICS + TRAVERSALS 30 MIN

Tree — kyun, kahan, aur kaise

Pehle problem dikhaunga (array aur linked list se kya dikkat hai), phir tree usse kaise bachata hai. Har cheez ka example, har formula ka kyun — aur brackets ⌈ ⌉ ka matlab bhi.

00

Tree kyun banaya gaya?

Pehle problem, phir solution — warna tree yaad rahega, samajh nahi aayega

Tumhare paas 10 lakh students ka data hai. Kisi ka roll number dhoondhna hai. Array me linear search? 10 lakh comparison. Linked list me? Wahi 10 lakh. Tree isi problem ka jawab hai.

❌ Array ki dikkat

Search: sorted ho toh binary search se O(log n) — par insert/delete me poora array shift karna padta hai → O(n). 10 lakh records me beech me ek insert = 5 lakh elements shift. Practically bahut slow.

❌ Linked list ki dikkat

Insert/delete: O(1) — bahut fast. Par search O(n), kyunki random access nahi hai (beech me pahunchne ke liye shuru se chalna padta hai). Binary search bhi nahi laga sakte.

✅ Tree (BST) — dono ka best

Search, insert, delete — teeno O(log n). 10 lakh records me sirf ~20 steps. Na shifting, na poora scan. Isliye database index, file system, dictionary — sab tree pe chalte hain.

Yaad rakho: tree ka poora fayda branching se hai. Har node pe decision lena = ek aadha data chhod dena. Isliye 10 lakh me sirf 20 step.

Sirf naam yaad mat karo — poochho "iski zaroorat kyun padi?"

1. General tree vs Binary tree
GENERAL TREE — koi bhi number of children

Ek node ke 3, 4, 10 bachche ho sakte hain. Jaise file system — ek folder me jitni files chaho.

BINARY TREE — max 2 children (left + right)

Sirf 2 — par isi limit ki wajah se formula aur traversal simple ho jate hain. Isliye poora syllabus binary tree pe hai.

03

Formulas — aur woh brackets kya hain

Pehle brackets, phir har formula ka "kyun"

Woh cut wale brackets — ⌈ ⌉ aur ⌊ ⌋

Inhe brackets hi kehte hain, par yeh rounding ke symbols hain — jaise calculator me "round off". Do tarah ke hote hain:

⌈x⌉
Ceiling — "chhat"

Hamesha upar wale poore number pe le jata hai.
⌈3.1⌉ = 4 · ⌈3.9⌉ = 4 · ⌈3⌉ = 3

⌊x⌋
Floor — "farsh"

Hamesha neeche wale poore number pe le jata hai.
⌊3.1⌋ = 3 · ⌊3.9⌋ = 3 · ⌊3⌋ = 3

Yaad rakhne ka tareeka: ceiling me chhat (upar) · floor me farsh (neeche). Symbol ka upar wala "kona" ⌈ upar dekhta hai, ⌊ neeche dekhta hai.

Formula 1 — Level i pe maximum nodes = 2ⁱ
Kyun 2ⁱ?

Root (level 0) = 1 node = 2⁰. Uske 2 bachche (level 1) = 2¹. Har bachche ke 2 bachche → level 2 me 4 = 2². Matlab har level pe nodes double ho jate hain.

Formula 2 — Height h wale tree me maximum nodes = 2^(h+1) − 1
Kyun?

Saare levels ke max nodes jod do: 1 + 2 + 4 + 8 + … (h+1 terms). Yeh geometric series hai — sum = 2^(h+1) − 1.

Example: height 2 → 2³ − 1 = 7 nodes (bilkul wahi tree jo Fig. 1 me hai). Height 3 → 2⁴ − 1 = 15. Height 4 → 31.

Formula 3 — n nodes wale tree ki MINIMUM height = ⌈log₂(n+1)⌉ − 1
h_min = ⌈ log₂(n + 1) ⌉ − 1

Yeh formula Formula 2 ka ulta hai. Formula 2 kehta hai "height h me max 2^(h+1) − 1 nodes aate hain". Toh agar tumhare paas n nodes hain, toh height kam se kam kitni chahiye ki wo fit ho jayein? Bas n ko 2^(h+1) − 1 me daal ke h nikaal lo.

Ceiling kyun? Kyunki height poore number me hoti hai — 3.46 level ka tree nahi banta. 10 nodes ke liye 3.46 aaya, matlab 3 levels me fit nahi hote (3 levels me max 7 nodes). Toh upar wala poora number lena padega → 4 − 1 = 3. Yahi ceiling ka kaam hai.

Formula 4 — Leaves ka relation: n₀ = n₂ + 1
Derivation (2 line me)

Total nodes: n = n₀ + n₁ + n₂ (leaf + 1-child + 2-child).
Edges = n − 1. Aur edges = children ki ginti = n₁ + 2n₂.
Barabar rakho → n₀ + n₁ + n₂ − 1 = n₁ + 2n₂ → n₀ = n₂ + 1 ✔

Example: 20 leaves wala strictly binary tree — kitne internal? n₀ = 20 → n₂ = 19 → kyunki strictly binary hai (n₁ = 0), total = 20 + 19 = 39 nodes.

04

Representation — array ya pointers?

Dono ke apne fayde, apni problem — poochho "kab kaunsa"

A. Array Representation (index se rishta)

Tree ko seedhe array me rakh do — rishta index ke formula se nikal aata hai:

FORMULA (0-based)

left child = 2i + 1
right child = 2i + 2
parent = (i − 1) / 2

KYUN KAAM KARTA HAI

Level 0 me 1 node, level 1 me 2, level 2 me 4 — yani har level pe index double hota hai. Isi liye 2i+1 aur 2i+2.

Example: Fig. 1 wala tree (A B C D E F G):

Index0123456
ValueABCDEFG

Check karo: B (index 1) ke children → 2(1)+1 = 3 (D) aur 2(1)+2 = 4 (E) ✔

❌ Problem — skewed tree me memory barbaad

Right-skewed tree (10 → 20 → 30 → 40) me sirf 4 nodes hain, par index 2i+2 chalte-chalte index 7 tak jagah chahiye. Height h ke skewed tree me array size 2^(h+1) − 1 lagta hai. Height 10 me sirf 11 nodes ke liye 2047 slots! Yahi array representation ki sabse badi dikkat hai.

✅ Kahan use karo

Complete binary tree me — kyunki wahan koi gap nahi hota. Isliye heap (priority queue, heap sort) array me hi store hota hai — koi pointer nahi, koi waste nahi, cache-friendly.

B. Linked Representation (pointers se rishta)

Har node me 3 cheezein — data, left pointer, right pointer:

struct node {
    int data;              // asli value
    struct node *left;     // left child ka address (ya NULL)
    struct node *right;    // right child ka address (ya NULL)
};

05

Traversals — tree ko padhne ke 4 tareeke

Naam me hi rule hai: N = Node, L = Left, R = Right

Traversal = tree ke saare nodes ko ek tay order me visit karna. Teen naam yaad rakhne ka tareeka — Node kab visit hota hai:

PREORDER — N L R

"Pehle khud, phir bachche."
Jaise attendance me teacher pehle apna naam bolti hai, phir students ka.

INORDER — L N R

"Left wale, phir khud, phir right wale."
Jaise line me beech ka banda pehle left wale ko jaane deta hai.

POSTORDER — L R N

"Bachche pehle, khud sabse baad me."
Jaise ghar khali karte waqt bachche pehle nikalte hain, bade baad me.

LEVEL ORDER

Level by level, left se right.
Jaise building me pehli manzil, phir doosri — queue se hota hai.
