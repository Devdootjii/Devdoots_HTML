04

B-Tree — intro

Jab data disk pe ho — binary tree kaafi nahi

❌ Binary tree ki disk pe problem

10 lakh records ka BST ≈ 20 level deep. Har level = ek disk read → slow.

✅ B-tree ka fix

Ek node me kai keys (jaise 100) → height sirf 3-4 → kam disk reads. DBMS aur file system isi ko use karte hain.

DEFINITION

B-tree of order m: har node me max m−1 keys, max m children · root ke kam se kam 2 children · baaki nodes ke kam se kam ⌈m/2⌉ children · saare leaves same level pe · keys sorted.

Order 3 ka matlab: ek node me max 2 keys. Teesri key aayi → node split — beech ki key upar.

10, 20 insert
  • 10, 20
2 keys — theek
30 aaya → overflow
  • 10, 20, 30
3 keys = 2 se zyada → split
Split ka rule: teen keys me se beech wali upar, baaki do left/right me. Yahan 20 upar, 10 left, 30 right.
