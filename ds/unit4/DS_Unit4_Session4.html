B-Tree — insert (order 5)

Order 5 = ek node me max 4 keys · 5 se zyada → split

RULES (order m = 5)

max keys = m − 1 = 4 · max children = m = 5 · saare leaves same level · split me beech wali key upar

Overflow kab hoga? — order pe depend karta hai

Order 4 ka example — 10, 20, 30 + 40

Order 4 hai → ek node me max 3 keys. 10, 20, 30 aane pe node bhar gaya; 40 aaya → overflow.

Kaun upar gaya? — BEECH wali key (20). Na sabse chhoti (10), na sabse badi (40). Split ke baad: left me [10], right me [30, 40], aur root me [20]. Root hi split hua, isliye height 1 badh gayi.
Convention: 4 keys me exact beech nahi hota — 20 aur 30 dono beech me hain. Standard (⌈m/2⌉) me 20 upar jata hai; doosri convention me 30 upar jata hai (left [10, 20], right [40]). Dono valid hain — exam me ek hi tarika follow karo.

B+ Tree — DBMS ka favourite

B-tree jaisa, par data sirf leaves me

FARK — ek line me

B-tree: data har node me ho sakta hai.
B+ tree: data sirf leaves me; andar ke nodes me sirf keys (raaste); aur saari leaves linked list se judi hain.

B+ tree (order 3)

DBMS B+ kyun use karta hai? Kyunki query aksar range ki hoti hai — "50 se 100 ke beech sab records". B+ me ek baar leaf tak pahuncho, phir linked list se aage badhte jao. B-tree me har node dobara dhoondhna padta.

Huffman Coding

File compression — chhote code zyada aane wale characters ko

STEPS (4)

1. Har character ki frequency lo, sabko min-heap me daalo
2. Do sabse chhoti nikalo, jodo → naya node (sum) → wapas heap me
3. Jab tak ek hi node na bache, repeat karo
4. Left edge = 0, right edge = 1 → codes mil gaye

Fayda: agar har character ko 3 bits (fixed length) dete toh 100 × 3 = 300 bits lagte. Huffman se 224 bits — yani 25% bachat. Isi liye ZIP, JPEG, MP3 me use hota hai.
Prefix property: koi bhi code doosre ka shuru (prefix) nahi hota — isliye decoding me confusion nahi hoti. Jaise 0 (f) kisi bhi doosre code ka shuruaati hissa nahi hai.

Complete binary tree + heap property = priority queue

DEFINITION

Max-heap: complete binary tree jisme har parent apne bachchon se bada ho (root pe sabse bada).
