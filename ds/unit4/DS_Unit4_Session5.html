04

B-Tree · B+ · Huffman · Heap

Chaar topics, har ek ka core ek card me

🌲 B-Tree (order m)
  • max keys m−1, max children m
  • overflow → beech wali key upar
  • root split → height +1
  • saare leaves same level
  • disk/DBMS ke liye (height kam)
🌿 B+ Tree
  • data sirf leaves me
  • leaves linked list se judi
  • range query fast
  • DBMS index isi ko use karta hai
📦 Huffman Coding
  • do sabse chhoti frequencies jodo
  • left = 0, right = 1
  • zyada aane wale ko chhota code
  • prefix property — decoding clear
  • a5,b9,c12,d13,e16,f45 → 224 bits (fixed 300)
⛰️ Binary Heap
  • complete tree + parent ≥ bachche (max-heap)
  • array: left 2i+1, right 2i+2
  • insert = bubble up O(log n)
  • delete root = heapify down O(log n)
  • build heap O(n) · root = max O(1)
Ek line me farak: B-tree/B+ = disk ke liye (kai keys ek node me) · Huffman = compression · Heap = priority queue (max/min turant chahiye).

Rapid-fire — 10 sawaal

Pehle khud bolo, phir "Jawab dekho" dabao

1. n₀ = n₂ + 1 kya batata hai?
Leaves ki ginti = 2-bachche wale nodes + 1. Example: 4 leaves → 3 nodes of degree 2.
2. 7 nodes wale tree ki minimum height?
⌈log₂(7+1)⌉ − 1 = ⌈3⌉ − 1 = 2
3. Inorder + Preorder se tree banta hai?
Haan, unique banta hai ✔ (preorder + postorder se nahi)
4. BST me 30 delete (do bachche) — kaun aayega?
Inorder successor = right subtree ka sabse chhota (Fig. 2 me 40)
5. BF ka formula aur allowed range?
BF = hL − hR · allowed −1, 0, +1
6. 30, 10, 20 insert — kaunsi rotation?
LR → pehle 10 pe left, phir 30 pe right · root 20
7. Order 5 B-tree me max keys?
m − 1 = 4 keys (max 5 children)
8. Split me kaunsi key upar jati hai?
Beech wali (median) — baaki do left/right me
9. B+ tree me data kahan hota hai?
Sirf leaves me · leaves linked · DBMS isi ko use karta hai
10. Max-heap me insert ki complexity?
O(log n) — bubble up height tak
